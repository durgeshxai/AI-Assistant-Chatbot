# AI-Chatbot-Web-App
# AI Chatbot Web Application

## Project Overview

This project is a simple AI Chatbot Web Application developed using Python, HTML, CSS, and JavaScript. The chatbot allows users to interact through a web interface and receive intelligent responses in real time.

The project consists of:

- Frontend Interface (`index.html`)
- Backend API (`chat_api.py`)
- Dependency File (`requirements.txt`)

The chatbot demonstrates the integration of frontend and backend technologies for building conversational AI applications.

---

# Features

- Interactive chatbot interface
- Real-time conversation handling
- API-based response generation
- Simple and responsive UI
- Frontend and backend integration
- Easy to run and customize
